# Transaction artwork

Assets are stored locally and rendered in the existing 40px merchant Avatar.

- Amazon: https://www.amazon.in/favicon.ico
- BESCOM: https://bescom.trm.ieasybill.com/Images/BESCOM_LOGO.png
- Swiggy: https://www.swiggy.com/corporate/wp-content/uploads/2026/06/Swiggy-orange-1-1-1-298x300.png
- Nykaa: website favicon retrieved through https://www.google.com/s2/favicons?domain=nykaa.com&sz=128
- BigBasket: official app artwork supplied by Apple's India software search for “bigbasket,” published by SUPERMARKET GROCERY SUPPLIES PRIVATE LIMITED.
- INOX: generic Phosphor film-strip symbol; https://github.com/phosphor-icons/core/blob/main/assets/fill/film-strip-fill.svg
- Gupta Stores: generic Phosphor storefront symbol; https://github.com/phosphor-icons/core/blob/main/assets/fill/storefront-fill.svg

The category symbols use the prototype's existing blue. They represent cinema and local-shop categories, not verified merchant logos.

Reference framing: cinema.svg and shop.svg include pale-blue rounded tiles and inset symbols. bescom-framed.svg embeds bescom.png inside a bordered white rounded tile. Outer artwork bounds remain 40px square.
