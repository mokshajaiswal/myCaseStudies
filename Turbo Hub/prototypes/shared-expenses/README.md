# Separate accounts, shared expenses

Alternative family finance concept; not part of the chosen manager-led Hub flow.
One phone screen, using the registered Turbo Hub components and shared preview shell.
Expenses and Balances switch in place. Settle up shows a review message; no money moves.
Fictional data uses two bills totaling ₹3,600 split equally between four family members.

Open `index.html` for the interactive preview. The case study and flow reference embed
this exact screen in story-preview mode. Catalog registration is `shared-expenses-alternative`.
