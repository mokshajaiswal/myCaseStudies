# Company icons

Local brand icons used beside the competitive-research company names.

- `revolut.svg`: main retail app icon from the [official Revolut logo package](https://developer.revolut.com/docs/resources/open-banking-logo-guidelines).
- `greenlight.svg`: Greenlight’s square GL mark from the [official website](https://greenlight.com/), asset `ic_gl_square.svg`.
- `monzo.svg`: Monzo’s M mark from the [official website](https://monzo.com/), SVG favicon.

The supplied SVG artwork is preserved. The case study renders each icon in a 28px square with its original proportions.
