# Interview stack interaction refinement

The previous stack rebuilt all button nodes when changing the quote, so its transform transition had no persistent element to animate. The new shared TurboInterviewStack renderer keeps every card mounted and turns the outgoing card edge-on over 180ms, then turns the next quote into view over 260ms. Repeated activations during the turn are ignored. There is no animation dependency.

The existing quote copy, user1–user4 labels, colored layers and stacked arrangement remain. A visible “Flip card” cue and position counter make the action discoverable. Hover gently turns the front edge, active presses it, and keyboard focus uses the card accent. Only the front card is accessible and interactive; background buttons are disabled and aria-hidden. Manual advancement moves focus without scrolling and announces the new position. Reduced motion swaps immediately and disables autoplay. The existing six-second autoplay pauses on hover, focus, document hiding and intersection loss.

Implementation and canonical specimen share components/interview-stack.js and interview-stack.css. The case study imports those files directly; the registered specimen supplies the same real quote content with autoplay disabled for inspection. This is an editorial component using existing case-study fonts/colors; it does not change mobile product controls. Parent layout owns the 448px maximum width, centering and research-section arrangement. The stack owns card inset (24px), quote/footer gap (16px), extra footer margin (8px), footer internal gap (16px), card sizing and motion. Registered scoped inset/gap tokens alias the incumbent case-study spacing. No registered mobile component internals were overridden.
