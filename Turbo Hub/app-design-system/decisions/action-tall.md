# Default Action sizing

Per the user’s direction, Tall is consolidated into the default Action. Standard labeled buttons now use --button-height:56px and --button-inset-y:16px; separate Tall renderer classes, tokens and previews have been removed. Compact remains 32px with 6px vertical inset, and icon-only remains 44px. Create a Hub Next now uses the default shared renderer. This applies to default Action consumers throughout the app. Browser review remains with the user.
